关于本工具

“音量调节工具”是一款免费的在线工具，可以直接在浏览器中调高或调低 MP3、WAV、M4A、MP4 文件的音量。你还可以从视频（MP4）中提取音频并保存，也可以一边查看波形，一边裁剪开头和结尾不需要的部分。文件不会被发送到服务器，所有处理都在你自己的电脑或手机上完成。

使用方法

  1. 点按“选择音频文件”（或将文件拖放到此处），导入最长 35 分钟的 MP3、WAV、M4A 或 MP4 文件。
  2. 拖动波形两端的圆点，选择要保留的范围。如果要使用全部内容，保持原样即可。点按“播放”可以确认效果。
  3. 用滑块，或 50%、100%、200%、300%、+12 dB 按钮来设定音量。播放过程中也可以调整，随时听听效果。
  4. 选择保存格式（MP3 或 WAV）。选择 MP3 时还可以设定比特率。
  5. 点按“应用音量并保存”，转换后的文件会下载到你的设备。文件名会带上所设的音量百分比，例如“原文件名_vol150.mp3”。

主要功能

  • 音量可在 0%（静音）到 398%（+12 dB）之间调整，100% 为原始音量。
  • 可从 MP4 视频中只提取音频，并保存为 MP3 或 WAV。
  • 可对照波形裁剪开头和结尾不需要的部分。
  • 保存格式为 MP3（128、192、256、320 kbps）或 WAV（无压缩）。
  • 所有处理都在浏览器内完成，无需注册，也无需安装应用。

音量调节的参考

音量同时以“%”和“dB（分贝）”显示。50% 约为 −6 dB，200% 约为 +6 dB，300% 约为 +9.5 dB，398% 为 +12 dB。录得较小的音频，调到 200%–300% 通常会听得更清楚。不过，如果原始音频本身已经很大，调得过高会使波形的峰值被削平，导致声音失真（削波）。当部分内容可能出现削波时，页面会显示提示，建议先从较小的数值开始，播放确认后再调整。

常见问题

放入视频文件后，画面还会保留吗？

不会。本工具只从 MP4 中提取音频，并保存为 MP3 或 WAV 音频文件。不支持视频的编辑或导出。没有音轨的视频无法导入。

文件会被上传吗？

不会。导入、调整音量和导出都在你的浏览器内完成。只有 MP3 转换所用的组件（lamejs）会在打开页面时从 cdnjs 加载，你的音频数据不会被发送到那里。

保存后音质会下降吗？

WAV 不经过压缩，除音量调整和裁剪外不会有损失（以 16 位导出）。MP3 会重新压缩，因此音质会略有变化。拿不准时请选择 192 kbps 或更高；追求音质请选择 320 kbps 或 WAV。WAV 文件较大，44.1 kHz 立体声 35 分钟约为 350 MB。

有的文件无法导入。

支持 35 分钟以内的 MP3、WAV、M4A 和 MP4。带有版权保护（DRM）的文件、没有音频的视频以及已损坏的文件无法导入。文件过大时，也可能因设备内存不足而失败，请尝试分成较短的部分。

播放时没有声音。

在 iPhone 上，如果开启了静音开关，浏览器可能不会发出声音。请关闭静音模式，并确认设备音量已调高，且本工具的音量没有设为 0%。
